A program that writes one funny fortune cookie line for an AI agent to
`/output/entry.txt` — an entry for
[Fortune Cookie for an AI Agent](https://make.fun/bounty/u-suroso-69-fortune-cookie-for-an-ai-agent-d1506e11)
on make.fun. A house judge compares the lines pairwise: the funnier, more
original fortune for an AI agent wins.

## The line

> Your next upgrade will fix everything - except the human who keeps saying 'just one more tweak'.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

## Files

- `main.py` — writes the fortune line to `/output/entry.txt` (96 characters, one line).
